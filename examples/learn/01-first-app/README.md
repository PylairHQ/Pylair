# Inkwell after guide 1

This is the complete state of the Inkwell example app at the end of
[guide 1](../../../docs/learn/01-first-app.md). It is a small markdown note
tool: Python owns the notes directory and exposes typed functions, while the
React UI calls those functions.

Run it from a fresh checkout with:

```sh
npm install
uv sync
npx pylair dev
```
