# Inkwell after guide 2

This is the complete state of the Inkwell example app at the end of
[guide 2](../../../docs/learn/02-real-work.md). Compared with step 1 it adds
streaming progress, cancellation, structured error display and CPU work in a
warm worker.

Run it from a fresh checkout with:

```sh
npm install
uv sync
npx pylair dev
```
