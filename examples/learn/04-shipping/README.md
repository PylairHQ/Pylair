# Inkwell after guide 4

This is the complete state of the Inkwell example app at the end of
[guide 4](../../../docs/learn/04-shipping.md). The application code is the
same as guide 3: the guide is about packaging, installing, signing and the
optional auto-update path rather than changing the app.

Run it from a fresh checkout with:

```sh
npm install
uv sync
npx pylair dev
```

Build the installed app with:

```sh
npx pylair build
```
